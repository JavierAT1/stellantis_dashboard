# Stellantis Vehicle Diagnostics Dashboard

Professional static enterprise dashboard for Heavy Duty Vehicle Traceability & Diagnostics.

## Run

Open `index.html` in a browser. The app uses local assets from `assets/images`, a local Lucide bundle, and Chart.js from the pinned CDN with canvas fallbacks for restricted networks.
